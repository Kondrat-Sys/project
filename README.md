# **Мобильное приложение — ИИ-чекер**

Потребность: Из-за стремительного роста качества генеративных нейросетей пользователи сталкиваются с фейками в новостях и соцсетях. Нужен простой инструмент, чтобы быстро проверить подозрительное фото или видео на признаки ИИ-генерации.

Основные результаты: Загрузка фото/видео из галереи или съемка на камеру. Анализ цифровых артефактов и метаданных. Выдача результатов анализа с процентом уверенности.



Как запустить: Нажмите на иконку приложения на рабочем столе.
